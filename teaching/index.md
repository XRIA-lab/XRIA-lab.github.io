# {% include icon.html icon="fa-solid fa-chalkboard-user" %}Teaching

We teach advanced courses that integrate XR, project work, simulation, and optimization, open to Bachelor's and Master's students at Uppsala University.

## Industrial Project with Extended Reality

10 credits · Advanced level

{%
  include figure.html
  image="https://i.ytimg.com/vi/mPG9GSacCGE/hqdefault.jpg"
  link="https://www.youtube.com/watch?v=mPG9GSacCGE"
  caption="Course overview (click to watch on YouTube)"
  width="560px"
%}

Students work on a full-scale XR project: designing, developing, and deploying an industrial application using VR, AR, or MR.
Topics include advanced project management (agile and extreme), ethical and inclusivity considerations, real-time data pipelines, and integrating XR tools with industrial systems.
